# Служба textrec на сервере

Особенности развёртывания этого проекта. Общая часть навыка — [SKILL.md](SKILL.md); шаги и параметры для скриптов —
[project.yaml](project.yaml).

## Зачем службе сервер

Telegram открывает Mini App только по постоянному адресу `https`, а бот должен работать, когда ноутбук выключен.
Адрес — `https://textrec.bazilio.ru/`. `GET /health` открыт; маршруты `/api/*` принимают только запросы с подписью
Telegram (`initData`) от пользователей из `telegram.allowedUserIds`. Бот получает обновления опросом, вебхук не нужен.

## Чего служба требует от сервера

- **DNS-запись `textrec.bazilio.ru` → 94.102.125.197.** Без неё certbot не выпустит сертификат, раздел nginx не
  запишется, и Mini App не откроется (бот при этом работает).
- **Доступ с сервера к api.anthropic.com и api.telegram.org.** Распознавание идёт через Claude Code из
  зависимостей проекта (`node_modules/@anthropic-ai/claude-code`) по токену подписки `recognition.oauthToken`
  (`claude setup-token`). Служба запускает Claude с отдельным каталогом настроек `<data.dir>/claude-config` и
  чистым окружением: глобальные настройки Claude пользователя root (там другой шлюз и модель) не подхватываются.
- **Ключ записи в репозиторий с учёбой.** Шаг `deploy` создаёт `notes.sshKeyPath` (`/root/.ssh/textrec-notes`) и
  печатает его открытую половину: её нужно добавить в `github.com/mishgancheg/study` → Settings → Deploy keys
  **с галочкой Allow write access**. Проверка — строка «Репозиторий с учёбой» в `status`.
- **Каталог данных** `data.dir` (`/opt/py/textrec-data`) вне рабочей копии: задания с фото (хранятся 30 дней),
  клон репозитория с учёбой, настройки Claude. Обновления и `uninstall` его не трогают.

## Разбор неполадок проекта

- **Распознавание падает с ошибкой** — `logs 100`. Истёкший или отозванный токен: выпустить новый
  `claude setup-token` на ноутбуке, вписать в `recognition.oauthToken` локального `config/local.yaml` навыка,
  `push-config`. Исчерпан лимит подписки — ждать сброса лимита.
- **Запись не сохраняется: «Не удалось отправить запись на GitHub»** — ключ не добавлен или добавлен без права
  записи. Клон в `<data.dir>/notes` при этом не ломается: неудачный коммит откатывается.
- **Бот молчит, в журнале `409 Conflict`** — тот же токен бота запущен где-то ещё (например, локально на ноутбуке).
